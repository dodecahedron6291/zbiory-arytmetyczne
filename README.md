# zbiory_arytmetyczne
Projekt zajmuje się obiektami zwanymi zbiorami arytmetycznymi. Są one sumą teoriomnogościową pewnej liczby ciągów arytmetycznych o stałej różnicy.
Można na nich wykonywać operacje, m.in.: suma, iloczyn, różnica, nalezy, moc.
Aby zbudować projekt wystarczy użyć komendy 'make' i uruchomić plik './ocen'.
